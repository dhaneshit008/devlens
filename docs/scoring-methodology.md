# Measurement and scoring policy

This version reports source file counts, detected supported-language counts, analyzed
UTF-8 byte counts, graph nodes/edges and import reachability counts. These are direct
measurements. Skipped entries and extraction limitations are visible alongside them.

There is **no overall repository health score**, security rating, bug probability,
coverage percentage, employee performance measure or calibrated AI confidence value.
Risk/health models are planned and must publish feature definitions, missing-data policy,
weights, thresholds, validation data and limitations before a score is exposed.

Test presence is a filename heuristic. Import counts do not measure runtime usage.
Supported-language detection excludes generated/vendor files and unsupported extensions;
it must not be presented as GitHub's whole-repository language statistics.
